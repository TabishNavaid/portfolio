# Tabish's Portfolio

A cozy desktop-style personal portfolio built with HTML, CSS, and JavaScript.

## Features

- day/evening/night scene transition
- draggable desktop popups
- custom doodle icons
- peeking profile interaction
- meadow cat music toggle
- UI sound effects
- responsive layout
- reduced-motion support

## Tech Used

- HTML
- CSS
- JavaScript

## Run Locally

Open `index.html` in a browser, or use a simple local server from the project folder:

```sh
python3 -m http.server
```

Then visit `http://localhost:8000`.

## Asset Note

Images and sounds live in `assets/images` and `assets/sounds`. Keep those paths the same so the doodles, sound effects, and background music continue to load.
